# 📊 Netflix Data Analysis & Visualization

## 🎯 Project Overview

This project analyzes and visualizes Netflix content to uncover key trends and insights.

### 🔍 Key Findings:
- Netflix focuses more on Movies than TV Shows, indicating a strong preference for movie production  
- The platform has experienced significant growth, especially after 2015  
- The United States leads content production, with other countries contributing increasingly  
- Most content targets mature audiences (TV-MA, TV-14)  

---

## 📊 Task 3: Data Visualization

- Built an interactive dashboard using Power BI  
- Created visualizations for:
  - Content distribution (Movies vs TV Shows)  
  - Content growth over time  
  - Top producing countries  
  - Ratings distribution  

---

## 🛠 Tools Used

- Power BI  

---

## 💡 Key Insights

- Movies dominate Netflix content  
- Content increased significantly after 2015  
- USA is the leading content producer  
- Most content targets adult audiences
